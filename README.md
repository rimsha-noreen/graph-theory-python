# graph-theory-python
Learning graph theory through mathematical concepts, Python implementations, and applications to Graph Machine Learning.
## Python Implementations

### 1. Graph Representation (`graph_representation.py`)

Represents a simple undirected graph using Python lists and tuples. The program defines vertices and edges, calculates their total numbers, and displays the graph structure.

**Concepts:** Graph theory, Python lists, tuples, variables, and the `len()` function.

### 2. Vertex Degree and Handshaking Lemma (`vertex_degree.py`)

Calculates the degree of each vertex using nested loops and conditional statements. The program also verifies the Handshaking Lemma:

∑ deg(v) = 2|E|, summed over all vertices v ∈ V.

**Concepts:** Vertex degree, nested loops, conditional statements, accumulation, and mathematical verification.

### 3. Adjacency Matrix (`adjacency_matrix.py`)

Constructs the adjacency matrix of a simple undirected graph using NumPy. The program calculates vertex degrees using row summation and verifies the Handshaking Lemma.

**Concepts:** Adjacency matrices, NumPy arrays, matrix indexing, `np.zeros()`, and `np.sum()`.

## Learning Objectives

This repository documents my progress in strengthening mathematical foundations and Python programming skills, with a particular focus on graph theory and its applications to Graph Machine Learning and Graph Neural Networks.
